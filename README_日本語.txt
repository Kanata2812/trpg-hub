TRPG HUB オンライン接続版（初期版）
====================================

このフォルダは、Supabaseへ接続するTRPG HUBの初期版です。

含まれる機能
- メールアドレスでの新規登録・ログイン
- シナリオ投稿・一覧・検索
- ショップ商品掲載・一覧・検索（決済なし）
- 交流掲示板・コメント
- Supabase Storageへの画像アップロード（5MBまで）
- スマートフォン対応

重要
- Publishable keyはブラウザ用の公開キーです。Secret key / service_role / DBパスワードは絶対にHTMLへ入れないでください。
- 現段階は初期版です。管理者専用ページ、カート、決済、注文管理、プロフィール編集、通報・モデレーション等はまだ未実装です。
- 本番公開前にメール認証設定、RLS、Storageポリシー、利用規約・プライバシーポリシー等を確認してください。
- ショップは商品掲載のみで、決済や売買契約を行いません。

公開方法の概略
1. index.html を含むフォルダをGitHubへアップロード
2. VercelでそのGitHubリポジトリをImportしてDeploy
3. Supabase Authentication > URL Configuration で公開サイトのURLを設定
4. 公開後、ログイン・投稿・画像アップロードをテスト

接続先は index.html に設定済みです。
